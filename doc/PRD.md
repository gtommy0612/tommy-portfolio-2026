# 個人多功能作品集網站 - 需求規格書 (PRD)

本規格書旨在定義「AI 協作開發、自行部署」之個人多功能作品集網站的技術架構、功能範疇、網站地圖（Sitemap）與跨平台品牌視覺一致性規範。

---

## 🛠 一、 技術棧與開發架構 (Tech Stack)

網站捨棄傳統臃腫的後台，採用 **Jamstack 現代前端架構**，達到極致的載入速度、資安防護與零維護成本。

*   **前端核心框架：** Astro (強力推薦，預設純靜態 HTML，SEO 頂級) 或 Next.js (React)
*   **樣式解決方案：** Tailwind CSS (利於 AI 輸出 Utility Classes，天然支援 RWD 斷點)
*   **基礎設施與部署：** GitHub 儲存庫 + Vercel / Netlify 全球 CDN 自動部署 (自備專屬網域)
*   **數據與事件追蹤：** 綁定 Google Tag Manager (GTM) 與 Google Analytics (GA)，針對關鍵轉換按鈕進行數據埋點。

---

## 🗺 二、 網站地圖 (Sitemap) 與精準分流網址

專為「兼職接案」與「數位變現」設計的扁平化結構，支援不同領域作品一鍵精準發射給目標客戶。

---

## 🔀 三、 核心功能範疇與外部平台導流地圖

透過成熟的 No-Code / Low-Code 工具整合，在「不寫自定義資料庫後台」的前提下完成商務閉環。

| 頁面 / 區塊 | 核心功能與使用者動作 | 底層運作與導流技術機制 | 網域狀態 (Domain) |
| :--- | :--- | :--- | :--- |
| **首頁 / 聯絡表單** | 填寫專案諮詢表單並點擊送出 | 透過 POST 請求將表單資料送至 **Formspree** API，自動觸發 Make/Zapier 流程推播至個人 **LINE Notify**。 | **留在原網域**<br>(無縫跳轉原生感謝提示) |
| **作品集頁面** | 點擊「查看線上實體專案」 | 導流至實際上線的客戶網站、產品官網或個人的 MVP 驗證落地頁。 | **開啟新分頁**<br>(外跳連結) |
| **作品集總覽** | 點擊分類標籤 (Web / Graphic) | 利用 React/Astro 動態狀態進行資料篩選（Filter），卡片需有流暢的 Tailwind 漸變動畫。 | **留在原網域** |
| **商店頁 (單次數位產品)** | 點擊「購買網頁模板 / Asset」 | 觸發 **Gumroad JS SDK**，於網頁中心彈出精美的結帳燈箱（Overlay Modal），直接完成付款。 | **留在原網域**<br>(使用者自始至終未離站) |
| **商店頁 (月費訂閱制)** | 點擊「訂閱微型設計特助」 | 內嵌 <b>Stripe Pricing Table</b>，點擊方案後安全跳轉至 Stripe 託管的客製化結帳頁面與客戶後台門戶。 | **跳轉至安全網域**<br>(Stripe 安全頁面) |

## 🎨 四、 品牌視覺一致性規範 (Design Tokens)

為防範使用者在自架網站與第三方平台（Stripe、Gumroad）流動時產生強烈的割裂感，必須嚴格執行以下規範：

### 1. Tailwind Config 視覺密碼
全站組件必須嚴格遵守以下視覺變數定義：
*   **品牌主色 (Brand Primary)：** `#0052FF` (電光藍)
*   **背景主色 (Background Dark)：** `#0B0B0C` (極致暗黑)
*   **輔助文字 (Text Muted)：** `#A0A0A5` (質感灰)

### 2. 第三方金流深度客製化
*   **Stripe Branding：** 必須登入 Stripe 後台（Settings → Branding），將結帳頁面的品牌色調整為 `#0052FF`，並上傳高解析度 SVG 品牌 Logo。

### 3. 使用者體驗預期 (Micro-copy & UI)
*   凡是產生分頁外跳的動作（如跳轉 Stripe 或外部 Live 專案），按鈕右側必須配置外跳圖示（如 `↗`）。
*   訂閱按鈕下方必須配置微文案提示：*“Secure checkout powered by Stripe. You will be automatically redirected back after completion.”*

## 🛍 五、 商店頁「落地頁式 (Landing Page)」包裝規範

商店頁面的產品呈現不得僅為冰冷的雜貨店網格，必須具備以下提升轉換率的設計元素：

1.  **動態預覽（Interactive Preview）：** 必須包含產品動態 GIF、影片展示或可嵌入式的 Demo 區塊，提供使用者「開箱感」。
2.  **痛點文案對比：** 以對比型文案包裝訂閱制（例如：「比請全職設計師省下 70% 成本，48 小時內隨叫隨到」），而非單純陳列服務項目。
3.  **免費誘餌（Lead Magnet）：** 付費產品旁必須配置一個「$0 元免費下載」的輕量版資源（如基礎 UI Kit），用以降低用戶體驗門檻，建立專業信任感。
4.  **FAQ 折疊選單（Accordion）：** 內建常見問題區，主動化解用戶對於「訂閱制規則、修改次數、取消政策」的疑慮。
